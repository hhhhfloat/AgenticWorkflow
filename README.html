⚙️ Agentic Workflow

基于 DeepSeek API 的本地 AI 编程助手
用自然语言描述需求，Agent 自动生成或修改代码

📌 环境要求

  • Windows系统
  • 需要安装 Java 21 或更高版本
  • 可下载： Oracle JDK
  • 安装后，在命令行输入 java -version 能正常输出版本信息即可

🚀 如何使用？

  1. 双击 start.bat
  2. 输入你的 DeepSeek API Key（首次运行会提示）
  3. 浏览器自动打开前端页面（本地运行，无服务器）
  4. 在文本框中输入需求，点击 “运行”

📝 v4.0 更新说明

  • 语义级代码结构解析：新增 get_file_structure 工具，支持 Java / Python / C++ / JavaScript / HTML / CSS 的文件结构解析，Agent 可直接“看懂”类、方法、字段和锚点
  • 精准锚点读取：新增 read_between_anchors，配合已有的锚点系统形成“先看结构 → 按需读取 → 精准修改”的完整闭环
  • 安全扫描模块：编译前自动拦截危险代码（系统命令执行、路径穿越），作为独立防护层
  • 上下文管理重构：三段式结构管理，便于操作与压缩
  • 前端优化：更流畅了
  • 修复了若干小 bug

📝 v3.x 更新回顾

  • 多语言编译运行：Java（单文件/Maven）、Python、Node.js、C++（MSVC/MinGW）
  • 锚点体系完善：insert_at_anchor + delete_between_anchors 实现代码块精准替换
  • 前端配置面板：无需修改代码，直接在界面中调整模型、路径等配置
  • 一键编译运行：Agent 编译成功的项目，前端直接生成运行按钮
  • API Key 管理：一键清除 API Key，自动删除环境变量并重启

📂 文件目录说明

  • sandbox/ → Agent 生成的所有代码都在这里
  • TestProjects/ → 归档的完整项目
  • HistoryOutput/ → 每次运行的日志文件
  • 以上几个文件夹会在 .jar 文件同级自动生成

⚠️ 注意事项

  • 需要联网（调用 DeepSeek API）
  • API Key 请从 platform.deepseek.com 官网获取（一点小钱够用挺久了）
  • 建议迭代次数设为 20+
  • 刷新页面会导致断连
  • 关闭命令行窗口即可停止服务
