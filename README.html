⚙️ Agentic Workflow

基于 DeepSeek API 的本地 AI 编程助手
用自然语言描述需求，Agent 自动拆解并执行完整项目任务

📌 环境要求

  • 跨平台支持（Windows / macOS / Linux）
  • 需要安装 Java 21 或更高版本（必须 21+）
  • 可下载： Oracle JDK 或 Eclipse Temurin
  • 安装后，在命令行输入 java -version 能正常输出版本信息即可

🚀 如何使用？

  1. 双击 start.bat（或终端执行 JAR 包）
  2. 首次运行会提示输入 DeepSeek API Key（也可提前设置环境变量 DEEPSEEK_API_KEY）
  3. 浏览器自动打开前端页面（本地 HTTP 服务，端口 8080）
  4. 在文本框中输入需求，点击 “运行”，Agent 将自动迭代执行

📝 v4.0 更新说明

  • 语义级代码结构解析：新增 get_file_structure 工具，支持 Java / Python / C++ / JavaScript / HTML / CSS 的文件结构解析，Agent 可直接“看懂”类、方法、字段和锚点
  • 精准锚点读取：新增 read_between_anchors，配合锚点系统形成“先看结构 → 按需读取 → 精准修改”的完整闭环
  • 安全扫描模块：编译前自动拦截危险代码（系统命令执行、路径穿越），作为独立防护层
  • 上下文压缩开关：前端配置面板新增「启用压缩模式」（默认开启）。开启后 Agent 可按需调用 request_checkpoint 自主产出状态摘要，大幅优化长上下文 Token 成本
  • 上下文管理重构：三段式结构管理（前缀+中间+后缀），中间段支持灵活压缩传递
  • A/B 测试工具：内置 JavaFX 桌面程序（testtool），可量化对比压缩模式开关的实际收益（轮数/成本/命中率）
  • 前端优化：文件树预加载更流畅，支持项目运行/归档/上传/新建全流程
  • 修复了若干小 bug

📝 v3.x 更新回顾

  • 多语言编译运行：Java（单文件/Maven）、Python、Node.js、C++（MSVC/MinGW）
  • 锚点体系完善：insert_at_anchor + delete_between_anchors 实现代码块精准替换
  • 前端配置面板：无需修改代码，直接在界面中调整模型、路径等配置
  • 一键编译运行：Agent 编译成功的项目，前端直接生成运行按钮
  • API Key 管理：一键清除 API Key，自动删除环境变量并重启

📂 文件目录说明

  • sandbox/ → Agent 生成的所有代码与运行沙箱
  • TestProjects/ → 归档的完整项目
  • HistoryOutput/ → 每次运行的日志文件（自动保留 30 天）
  • testPortfolio/ → A/B 测试报告与对比图表（使用 testtool 时生成）
  • 以上文件夹会在 .jar 文件同级自动生成

⚠️ 注意事项

  • 需要联网（调用 DeepSeek API）
  • API Key 请从 platform.deepseek.com 官网获取（成本极低，充值少量即可长期使用）
  • 建议迭代次数设为 20+ 以完成复杂任务
  • 刷新前端页面会导致当前 SSE 连接断开，但 Agent 可能仍在后台运行（可观察控制台日志）
  • 关闭命令行窗口即可停止后端服务

🐛 遇到问题？

  • 无法连接 DeepSeek？检查网络或 API Key 是否配置正确
  • 中途断连？可能是刷新了前端网页或网络不稳定
  • 编译报错？请确保本地已安装对应语言的编译器（如 GCC、Python、Node.js 等）
