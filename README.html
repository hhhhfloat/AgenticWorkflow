⚙️ Agentic Workflow

基于 DeepSeek API 的本地 AI 编程助手
用自然语言描述需求，Agent 自动拆解并执行完整项目任务

📌 环境要求

  • 跨平台支持（Windows / macOS / Linux）
  • 需要安装 Java 21 或更高版本（必须 21+）
  • 可下载： Oracle JDK 或 Eclipse Temurin
  • 安装后，在命令行输入 java -version 能正常输出版本信息即可

🚀 如何使用？

  1. 双击 start.bat（或终端执行 JAR 包）
  2. 首次运行会提示输入 DeepSeek API Key（也可提前设置环境变量 DEEPSEEK_API_KEY）
  3. 浏览器自动打开前端页面（本地 HTTP 服务，端口 8080）
  4. 在文本框中输入需求，点击 “运行”，Agent 将自动迭代执行

📝 v5 更新

  • 前端md预览：前端目录树的md文件可点击预览
  • 修复了若干小 bug 和锚点系统的大 bug

📝 v4 更新回顾

  • get_file_structure获得文件结构；read_between_anchors精确读取；安全扫描；上下文自压缩；对比工具>
  • 修复了若干小 bug

📂 新版文件目录说明

  • sandbox/ → Agent 生成的所有代码与运行沙箱
  • TestProjects/ → 归档的完整项目
  • HistoryOutput/ → 每次运行的日志文件（自动保留 3000 天）
  • sessions/ → 对话记录
  • temp/ → 完整上下文记录，生成时压缩成gz
  • agent-config.properties → 程序找到的编译工具位置
  • 以上文件(夹)会在 .jar 文件同级自动生成

⚠️ 注意事项

  • 需要联网（调用 DeepSeek API）
  • API Key 请从 platform.deepseek.com 官网获取（成本极低，充值少量即可长期使用）
  • 建议迭代次数设为 20+ 以完成复杂任务
  • 刷新前端页面会导致当前 SSE 连接断开，但 Agent 可能仍在后台运行（可观察控制台日志）
  • 关闭命令行窗口停止后端服务

🐛 遇到问题？

  • 无法连接 DeepSeek？检查网络或 API Key 是否配置正确
  • 中途断连？可能是刷新了前端网页或网络不稳定
  • 编译报错？请确保本地已安装对应语言的编译器（如 GCC、Python、Node.js 等）
